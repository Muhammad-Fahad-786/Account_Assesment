# Contributing to Banking Assessment Project

Thank you for your interest in contributing to this project!

## Project Structure

This is a full-stack banking system built with:
- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Database**: MongoDB

## Development Setup

1. Clone the repository
2. Set up backend (see README.md)
3. Set up frontend (see README.md)
4. Start development servers

## Code Style

- Follow existing code patterns
- Use meaningful variable names
- Add comments for complex logic
- Keep functions focused and modular

## Commit Messages

Use clear, descriptive commit messages that explain what and why.

## Testing

Before submitting changes:
- Test all features locally
- Verify API endpoints work correctly
- Check for console errors
- Ensure responsive design works

## Questions?

Feel free to open an issue for questions or suggestions.
