# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024

### Added
- Initial release of Online Bank Mini System
- Account creation with unique account numbers
- Deposit money functionality
- Withdraw money with balance validation
- Transfer money with KYC verification
- Account listing view
- Modern React frontend with Vite
- Express.js backend API
- MongoDB database integration
- Comprehensive error handling
- Input validation
- CORS configuration for cross-origin requests
- Deployment configuration for Vercel and Render

### Features
- Create bank accounts with holder name and initial balance
- Deposit funds to accounts
- Withdraw funds with sufficient balance check
- Transfer funds between accounts (KYC verified required)
- View all accounts with details
- Clean, responsive UI
- Real-time error and success messages

### Technical Details
- Frontend: React 18, React Router, Axios, Vite
- Backend: Node.js, Express.js, MongoDB, Mongoose
- Deployment: Vercel (frontend), Render (backend)
